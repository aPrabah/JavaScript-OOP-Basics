# JavaScript OOP Basics

A small JavaScript project exploring different ways of creating and organizing objects using object literals, constructor functions, and ES6 classes.

## What It Demonstrates

- JavaScript object literals
- Constructor functions
- ES6 class syntax
- Prototypes and shared methods
- Basic object-oriented programming concepts
- Refactoring code into a cleaner structure

## Project Structure

The project implements the same functionality in three different ways:

- `plainObjects.js` – object literals
- `constructorFunctions.js` – constructor functions
- `classNotation.js` – ES6 classes

Each version produces the same result while demonstrating a different approach to structuring JavaScript objects.

## About

Originally developed for a university web development course as an introduction to object-oriented programming in JavaScript.
